Ausführliche Informationen zum Thema Datenschutz entnehmen Sie unserer unter diesem Text aufgeführten Datenschutzerklärung.

Datenerfassung auf dieser Website

Wer ist verantwortlich für die Datenerfassung auf dieser Website?

Die Datenverarbeitung auf dieser Website erfolgt durch den Websitebetreiber. Dessen Kontaktdaten können Sie dem Abschnitt „Verantwortliche Stelle" in dieser Datenschutzerklärung entnehmen.

Wie erfassen wir Ihre Daten?

Diese Website erhebt keine Daten durch aktive Eingabe, außer wenn Sie freiwillig einen Termin über unser Buchungssystem buchen. Technische Daten (z. B. IP-Adresse, Browsertyp) werden automatisch durch die verwendeten Server erfasst.

Die Daten werden ausschließlich zur Bereitstellung dieser Website sowie — nach Ihrer ausdrücklichen Einwilligung — zur Verwaltung von Terminbuchungen genutzt.
